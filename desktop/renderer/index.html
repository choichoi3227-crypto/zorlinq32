Zorlinq32

워드프레스 내장 브라우저

등록한 사이트를 선택하면 앱 내부 프레임에서 워드프레스 관리자 화면을 열 수 있습니다. 애플리케이션 비밀번호는 REST API 자동 작업에 사용됩니다.

글쓰기

원격 설정에 Cloudflare Worker와 Gemini API 키를 저장하면 앱에서 초안 생성 또는 원격 글쓰기 요청을 실행합니다.

사이트 관리


    


    

      
플러그인/테마 관리

      

      
이 앱 패키지에는 zorlinq32 워드프레스 플러그인 폴더가 함께 포함되도록 빌드 설정했습니다.

      

    


    

      
Google Flow 이미지 생성

      
최초 1회 Flow 로그인으로 사용자 브라우저에서 계정을 연결하고, 이후 이미지 생성 시마다 사용자 기본 브라우저에서 Flow를 엽니다.
