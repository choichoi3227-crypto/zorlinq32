=== Zorlinq32 ===

AI 글쓰기와 WordPress 관리 도구를 제공합니다.

== 이미지 생성 ==

이미지 생성은 Google Flow 팝업을 통해 사용자가 수행합니다. 플러그인은 생성 프롬프트를 클립보드에 복사해 Google Flow에서 붙여넣을 수 있게 합니다. Google Flow는 외부 사이트이므로 로그인, 프롬프트 입력, 생성 완료와 결과 파일 다운로드를 플러그인이 자동 제어하지 않습니다.

== AI 글쓰기 검색 ==

Cloudflare Worker URL과 Shared Secret은 AI 글쓰기 검색 그라운딩에만 사용됩니다. 이미지 생성 또는 이미지 키워드 조사 요청에는 사용되지 않습니다.
